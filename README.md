# Top-down Fighter
## A Global Gamejam 2026 Project

As part of GGJ 2026 theme, the game utilizes masks as pickup-able power ups, giving the player different moves and abilities depending on the mask being worn. Similarly, the enemies may also wear these masks that provide different attack moves, patterns, or stats. However, the game is intended to be clearable even if the player wears the simple “starting mask”, giving the player only basic moves with no special abilities.

## Gameplay overview
The player will move through the level fighting enemies and reaching the finishing point (the exit door), unlocking the next level. Upon entering the new level, all stats are reset and the player wears no mask.

At the final level, the player will fight the last boss. Beating the boss will finish the game.
